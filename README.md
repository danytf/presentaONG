# Formaciones ONG

Programa de formación · Captación de socios.

Presentaciones interactivas con la historia, programas, cifras de impacto y argumentario
de captación de cada organización.

## Organizaciones

- AECC
- Aldeas Infantiles
- Cruz Roja
- FEC
- FJC
- FPM
- WWF

## Estructura

- `index.html` — portada con el acceso a todas las formaciones.
- `bundled/` — una presentación autocontenida por organización (HTML con todos los
  recursos embebidos: fuentes, imágenes y estilos).

## Uso

Abre `index.html` en el navegador y elige una organización. No requiere servidor ni
instalación: cada presentación funciona por sí sola.
